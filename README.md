# RC-CAR RWD — project website

Static HTML/CSS site for `rccar-rwd.github.io`. No build tools, JavaScript, or external dependencies.

## Publish
Upload `index.html`, `style.css`, `README.md`, and the `assets/` folder into the repository root. In Settings → Pages select Deploy from a branch → main → /(root) → Save. If the repository already has a README, merge or replace it deliberately.

## Update
- Edit `index.html` for text, team, timeline and test results.
- Edit `style.css` for design.
- Place approved project images in `assets/` and reference them from HTML.
- Replace both project member placeholders with names, actual responsibilities and approved profile links.
- Add credits and licensing for third-party mechanical reference designs; review permission to publish CAD-derived images and PCB layouts before upload. If not approved, remove the corresponding image and link or replace them with authorized photos.
- PCB illustrations are derived from supplied vehicle and controller PDF layout pages (3 and 2 respectively); mechanical illustrations are rendered from the supplied Chassis.stl and Front.stl. They are design views, not photographs or proof of final assembly. No raw CAD, schematic PDFs, private logs or source code are included.
- Add measured results and approved demo links after validation; do not treat targets as measured results.

Preview by opening `index.html` locally. All links and images use static paths. The GitHub organization link is based on the owner-provided name.
